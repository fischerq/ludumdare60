# Art from Max

Edited art comes back here with the same paths as the export in `assets/` (e.g. `pac-0.png`,
`maze/wall-3.png`): one PNG per sprite or tile, native size, transparent. Sprites may be 32x32. The game loads a file from here instead of the code-drawn one
once it's wired in (see `design/systems/art.md`).
