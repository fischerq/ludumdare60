What's Ludum Dare?

  • One of the oldest online game jams, running since 2002. Thousands of people make a game over the same weekend.
  • The theme is picked by community voting on ldjam.com and revealed when the jam starts.
  • Compo: 48 hours, solo, everything made from scratch, source code included. Jam: 72 hours, solo or in a team, with looser rules.
  • Any engine or tool is fine, and so are first-timers. Afterwards everyone plays and rates each other's games.

Full rules: ldjam.com/events/ludum-dare/rules

Hosted by
