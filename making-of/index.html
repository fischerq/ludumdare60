How this game was built

Every prompt a human sent to Claude while building this game, in order, with what Claude did, how long it took and what it cost. Nothing is edited out.

How to read the numbers
  • Prompt: a message a human typed, shown verbatim.
  • Claude's reply: the final message Claude showed after working. Progress notes it wrote along the way are folded underneath.
  • Tokens: how much text the model read and wrote. Each tool call re-reads the conversation, so "read" is large but mostly served from a cheap cache.
  • Cost: what those tokens would cost at Anthropic's public API prices. It's computed from the exact token counts Claude Code logs.
  • Plan: how much of the subscription's rolling 5-hour and weekly usage limits went up between this prompt and the next one. It's read from Claude Code's own rate-limit events, which have 1% resolution.
  • Time: from sending the prompt to Claude's last action, including running the game in a headless browser to check it.
